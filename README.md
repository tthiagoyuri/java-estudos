# ☕ Estudos em Java

Repositório dedicado aos exercícios e projetos desenvolvidos durante meus estudos em Java.

O objetivo deste repositório é registrar minha evolução na linguagem, praticando desde conceitos fundamentais até Programação Orientada a Objetos.

## 📚 Conteúdos estudados

- Entrada e saída de dados
- Estruturas condicionais

- Métodos
- Funções matemáticas

### Programação Orientada a Objetos
- Classes e objetos
- Métodos
- Construtores
- Sobrecarga de construtores
- Encapsulamento
- Modificadores de acesso
- Membros estáticos
- toString()

### Estruturas de dados
- Vetores
- Vetores de objetos
